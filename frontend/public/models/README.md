# 3D Avatar Models

Place your 3D model file here as:
`avatar.glb` (or `avatar.gltf`)

### Features
- **Automatic Fallback**: If no custom `.glb` is provided, InterviewAI renders a built-in high-fidelity sci-fi robot with glossy white chassis and glowing cyan/blue eyes that smoothly tracks the user's cursor on hover.
- **Custom Model Loading**: When `public/models/avatar.glb` is placed in this folder, InterviewAI will automatically load and display your custom 3D model with cursor hover tracking!
- **Supported Formats**: `.glb` (recommended binary format) or `.gltf` with embedded textures.
